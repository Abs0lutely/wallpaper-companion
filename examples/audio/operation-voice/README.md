# 随程序分发的默认操作语音

此目录预留给 52 条默认操作台词的正式音频，目前没有真实配音，不能将测试 WAV 当作配音发行。

台词清单在 `examples/dialogues/operation-zh-CN.json`，26 个分类各两条。可在软件台词库点击“导入默认操作台词”，全选这 26 个“操作·…”分类，使用“按分类生成勾选台词”。生成结果应为 `音频根目录/操作·保存/让我把这份心意好好收起来。.wav` 等结构。请保留 JSON 分类与完整台词文件名，普通 TXT 不携带分类信息。

软件按“设置的自定义操作目录 → 共享语音目录 → 本目录”的顺序，逐类寻找对应音频。缺失分类保持静音，并在设置中显示覆盖数量；播放不会启动任何生成服务。

维护者准备分发音频时执行：

```powershell
.\.conda\python.exe scripts/prepare_operation_voice_pack.py --source "生成的音频根目录"
# 确认 52 条齐备、听评内容和音质，并确认这些配音可随项目公开分发后：
.\.conda\python.exe scripts/prepare_operation_voice_pack.py --source "生成的音频根目录" --apply
```

脚本只复制清单中的 WAV，不复制个人其他台词、音乐或模型；遇到目标已有不同内容时停止，需先人工审阅。默认只校验，不复制。完整构建入口在生成 EXE 前检查这 52 条音频，缺失、无效或全零静音会阻止发行。现有构建脚本会把整个 `examples/` 放进安装包和便携包；本目录的正式素材也会随之分发。
