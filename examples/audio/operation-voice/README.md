# 随程序分发的默认操作语音

本目录已纳入 51 条用户提供并授权随程序分发的默认合成语音，覆盖全部 26 类软件操作。相邻 `starter-voice/` 提供另外 26 条陪伴示例，共 77 条，约 26.8 MiB。原始用户音频保留未改；这些副本不含模型、参考音频、API 配置或个人台词。

台词清单在 `examples/dialogues/operation-zh-CN.json`，26 类各两句。目前只缺“这些小小的安排，都值得被认真记住。”这一可选变体；同类另一句已存在。另有返回桌面、闲置陪伴两类共 12 条普通台词尚未生成。`examples/dialogues/missing-default-audio-zh-CN.json` 收集这 13 条，若需补齐可以直接导入，现有音频不必重做。

软件按“设置的自定义操作目录 → 当前编辑配置语音目录 → 共享语音目录 → 本目录”的顺序，逐类寻找对应音频。缺失分类保持静音，并在设置中显示覆盖数量；播放不会启动任何生成服务。

“设置 → 操作回应规则…”独立控制每种操作的启用、分类和冷却，默认全部开启。规则 JSON 为 `examples/presets/operation-voice-rules.json`，不会改写壁纸互动规则。

维护者新增/补齐分发音频时执行：

```powershell
.\.conda\python.exe scripts/prepare_default_audio.py --source "生成的音频根目录"
# 审阅内容与音质并确认可随项目分发后，复制清单内文件并更新总清单：
.\.conda\python.exe scripts/prepare_default_audio.py --source "生成的音频根目录" --apply
```

脚本只复制两套默认台词白名单内的 WAV，不复制个人其他台词、音乐或模型；遇到目标已有不同内容时停止。默认只校验，不复制。`examples/audio/manifest.json` 保存每条副本的分类、台词、长度及 SHA256，不携带本机路径。构建前验证清单内外文件一致、PCM WAV 有效且不全零，并要求 26 类操作每类至少一条；第二句变体不是必须项。实际 EXE 自检也检查哈希。

已有总清单时，旧的 `prepare_operation_voice_pack.py --apply` 会提示改用上述完整准备入口，防止只复制操作文件而遗漏总清单。现有构建脚本将整个 examples 放入 ZIP 和安装包，便携更新器的 examples 白名单同样覆盖这里。运行中这些文件受保护，只能在音频库试听或复制，不可删除、覆盖；不会复制到或覆盖个人目录。

本轮验证了格式、哈希和实际播放器播放；未执行逐句听评或 ASR 原文核对，不把文件名匹配当作语音内容核验。

新生成的文件名为“台词-模型名称.wav”；现有 77 条纯台词文件名保持不变。查找与校验兼容两种格式。准备脚本会保留来源文件名；同一句有多个模型版本且没有旧的标准文件可明确选择时会停止，需先整理选定要分发的版本，不能悄悄挑选一种音色。
