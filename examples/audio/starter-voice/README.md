# 随附陪伴示例语音

38 条用户提供的默认台词配音，包含点击回应、返回桌面、早晨、白天、夜间和闲置陪伴；对应 `companion/dialogues.py` 的默认文本。详细文件、SHA256、时长见本目录 `manifest.json`，总清单见上层 `manifest.json`。

新配置默认开启“语音目录为空时使用随附示例”，通过规则或随机试听直接读取这里；自己的语音目录有文件时优先使用个人文件。旧配置缺少此字段时默认关闭。这里不写入个人目录、不修改壁纸，音频库视为只读，可复制出自己的副本。

返回桌面和闲置陪伴两类各 6 条已补齐，并保留来源的模型标签文件名。`examples/dialogues/missing-default-audio-zh-CN.json` 为已完成任务的参考清单。新配置默认 F8/随机规则可使用全部 38 条示例，指定分类规则也可直接读取对应示例。
