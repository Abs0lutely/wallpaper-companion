# 温柔回信：原创中文台词包

需要其他语言？另提供默认台词的 **[日语 / 英语版本](TRANSLATIONS.md)**：每种语言 38 条陪伴台词与 52 条操作回应，均有可导入 JSON、阅读版 TXT 及对应操作规则。它们是默认 90 条的翻译，不是本页 72 条台词的翻译，不包含新生成的配音。

72 条原创台词，偏温柔、煽情和日常安慰；六个分类各 12 条，与默认分类触发规则对应。可在项目 MIT 许可下使用、修改及分享，不是游戏或影视原台词。

推荐导入 **heartfelt-zh-CN.json**：保留点击回应、返回桌面、早晨、白天、夜间、闲置陪伴分类。TXT 是方便阅读的逐行文本，导入时会按程序 TXT 规则统一归到“点击回应”。

在软件中打开“台词库 → 导入台词 JSON / TXT”，选择 JSON，再点击“保存台词库”。相同分类和文本不会重复添加。文字导入不会调用 API，也不会立即发声；之后可勾选条目，使用“按分类生成勾选台词”。

**v0.8.0 兼容操作：** 尚未绑定壁纸时，先在“陪伴主页 → 配置管理 → 新建配置”创建一个配置，再去台词库导入并保存。不必先有实际壁纸。v0.8.1 起，无壁纸配置也可以直接导入和保存共享台词。

台词是桌面伴随作品的创作素材。可按角色语气删改标点、称呼和长度；参考音频原文仍需逐字对应参考音频，不能用这些待合成台词替代。
