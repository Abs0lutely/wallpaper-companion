## 壁纸声伴 v0.11.0 · 多语言配音与一键陪伴包

这次合并了“多语言配音与独立声音伴随”和“一键陪伴包”两批更新。

### 开箱体验

- **无需 Wallpaper Engine 也能用**：新增独立声音伴随模式，保留按键、鼠标、定时语音和 BGM。原来的 WE 绑定与模式选择分别保存。
- **选包 → 试听 → 使用**：主页新增陪伴包入口。中、日“温柔日常”各有 38 条陪伴录音和 52 条可选操作回应，合计 180 条获准分发的默认录音，无需 AI 即可体验。
- **离线分享**：支持 `.wcpak` 导入、预览、新建独立方案与切回原方案；在配置管理导出单个方案，可选择文件、BGM 和操作回应。操作回应默认不随包启用；缺少配音会明确说明，不自动调用 AI。

### 多语言与资源管理

- 操作回应可快速切换中、日、英默认分类；日英分类统一 `·ja-JP` / `·en-US` 后缀，支持旧译文迁移预览与受限旧目录兼容，不移动个人音频。
- 台词生成统一送到生成页，保留分类和重复检查；编辑文本时提示分类信息变化。
- 目标/参考语言使用可编辑下拉框；生成前提示可能的语言不符，可返回修改或继续，确认前不启动 API。文字启发式不能验证模型训练语言。
- 共用台词 JSON 支持编辑、浏览、安全切换和解除关联；文件选择器从当前路径或最近存在的父目录开始。
- 新增界面和使用文档均提供中英文；界面语言与配音选择互相独立。

### 下载

- **setup.exe**：当前用户安装或升级。
- **portable.zip**：完整解压后运行 `WallpaperCompanion.exe`，不要只取出 EXE。
- **SHA256SUMS.txt**：核对两个程序包的 SHA256。
- 其余 JSON/TXT 为额外台词和规则素材；英语及《温柔回信》文字仍需自行配音。

程序不修改 WE 或壁纸文件；升级/卸载按原规则保留用户数据。此次没有更新或删除开发者本机的个人安装版。导出素材前请确认有权分发。

### 验证范围

本地隔离回归、包安全/失败回滚和中英文原生流程通过；真实 Qt 播放覆盖中日示例及导出 BGM。WE/输入环境和 API 使用模拟，未声称实测第三方合成。云端流程在发布前另行构建、验证实际便携 EXE、安装版及卸载保留数据，新增随附包导出/导入自检。

## English

Two feature updates in one release: multilingual voices/standalone companionship, and offline companion packs.

- Use **standalone sound profiles without Wallpaper Engine**, keeping existing WE links separate.
- **Choose → Preview → Use** an included Chinese or Japanese pack. Each contains 38 companion clips and 52 optional app responses: 180 approved recordings total. No AI is needed for these recordings.
- Import/export offline **`.wcpak`** files, review selected resources, optionally include BGM/app responses, and return to the previous setup. App responses require explicit opt-in; missing recordings never silently start AI.
- Quickly switch default operation categories between Chinese/Japanese/English; translated categories use `·ja-JP` / `·en-US`. Preview legacy category migration without moving personal audio.
- One dialogue-generation route preserves categories and duplicate checks. Editable target/reference language choices and conservative preflight warnings allow returning to edit or continuing before API startup.
- Safely browse/change/detach shared dialogue JSON files; file dialogs start at the current path. New UI and documentation are bilingual; interface and voice languages remain independent.

Download **setup.exe** for installation, or extract the entire **portable.zip**. **SHA256SUMS.txt** covers both binaries. Extra JSON/TXT files are dialogue/rule material; English and Gentle Replies text still require recordings.

Local isolated regressions and actual Qt sample/BGM playback passed. WE/foreground/API tests use mocks, not real third-party synthesis. The cloud release verifies the real frozen portable/installed applications, pack roundtrips and uninstall data preservation before publication. WE/wallpaper files and personal installations are not modified.
