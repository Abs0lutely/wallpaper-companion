# v0.12.0 — 自动更新与陪伴包规则修复

## 中文

- 新增默认开启的自动更新：后台检查正式版并下载，展示进度、版本与更新说明，经确认后保存、退出、更新并重启。可以关闭，也可以手动检查。
- 安装版和便携版分别下载匹配的附件，校验大小与 SHA256；保留个人配置、壁纸绑定、台词、音频、陪伴包及插件。便携版保留程序备份并支持失败回退。
- 生成任务进行中、保存失败或其他实例仍在运行时，不强制退出安装。
- 修复导入无 BGM 或纯文字陪伴包后，修改互动规则时提示目录不存在的问题；已有包在保存时兼容修复。
- 中英文手册补充更新说明。**旧版用户需手动安装此版本，之后才能使用内置自动更新。** Windows 的未签名程序信誉提示不在此更新中消除。

## English

- Automatic updates are enabled by default: check stable releases, download in the background and show progress and release notes. Save, exit, install and restart only after confirmation. Opt out or check manually in settings.
- Matching installed/portable packages are verified by size and SHA256. Personal settings, bindings, dialogues, audio, companion packs and plugins are retained. Portable updates keep a program backup and roll back failed replacements.
- Active generation, failed saves and other running instances block installation without forcing applications to close.
- Fixed rule saving after importing voice-only or text-only companion packs; existing pack profiles are repaired when saved.
- Updated bilingual help. **Install this version manually to enable in-app updates for future releases.** Unsigned-app Windows reputation prompts may still appear.

## 验证 / Validation

本次正式发布须通过 Windows checks、实际冻结 EXE、安装卸载，以及由独立辅助程序从真实 v0.11.0 安装版/便携版升级的验证。仅使用隔离数据；未调用个人语音服务或测试真实 WE 音频检测。

Publication is gated on Windows checks, real frozen EXE and installation tests, and detached-helper upgrades from actual v0.11.0 installed and portable packages. Validation uses isolated data; personal speech services and real Wallpaper Engine audio detection are not exercised.
