# v0.13.0 — 更低常驻内存与资源浏览提速 / Runtime performance

## 中文

- 托盘启动按需创建配置页面，减少后台常驻内存；播放、规则、BGM 和自动更新在尚未打开窗口时仍可运行。
- 统一音频资源索引，合并扫描请求，监测资源变化；大列表改用 Qt model/view，限制缩略图缓存，减少重复读取和控件开销。
- 耗时任务与短时查询分开调度，限制排队与并发；切换配置和退出时忽略过期回调，隐藏页面停止装饰刷新。
- 保留现有界面风格、JSON 配置、插件提供方接口和命令行；自动更新仍在用户确认后安装，保留个人资源。
- 本机 Windows 隔离测试：十分钟托盘末一分钟私有内存约 **116.9 → 67.2 MiB**；1000 资源列表填充中位数，音频 **56.1 → 1.9 ms**、壁纸 **71.2 → 9.1 ms**。三十分钟完成 904 次切换/刷新，末两段五分钟内存中位数约 **128.453 → 128.457 MiB**，未观察到持续增长。
- 采用低常驻内存方案的取舍：托盘首次开窗中位数 **0.87 → 2.39 秒**，后续热重开约 **64 ms**。性能结果来自本机合成资源与模拟外部服务，不代表所有电脑、真实 WE 或合成服务的速度；首次访问页面成本已计入报告。

## English

- Create editor pages on demand to reduce tray memory. Playback, rules, BGM and automatic updates remain available before opening the editor.
- Reuse a bounded audio index, coalesce scans and watch resource changes. Model/view lists and bounded thumbnail caching reduce repeated reads and persistent widgets.
- Separate slow jobs from short queries, bound queues and concurrency, discard stale callbacks after profile changes or shutdown, and suspend decorative refreshes on hidden pages.
- Preserve the visual style, JSON configuration, provider interfaces and command-line usage. Updates still require confirmation before installation and preserve personal resources.
- Local isolated Windows measurements: final-minute private memory after ten minutes in the tray was approximately **116.9 → 67.2 MiB**. For 1,000 resources, median list population was **56.1 → 1.9 ms** for audio and **71.2 → 9.1 ms** for wallpapers. A 30-minute run completed 904 profile transitions/refreshes; the final two five-minute memory medians were **128.453 → 128.457 MiB**, with no sustained growth observed in this workload.
- The chosen low-memory mode trades first tray opening latency (**0.87 → 2.39 seconds**) for lower residency; subsequent reopening takes about **64 ms**. These are local synthetic-data measurements with mocked external services, not guarantees for every machine, real Wallpaper Engine or speech inference. First-use page costs are included in the reports.

## 验证 / Validation

源码已通过 177 项单元测试、30 个原生界面流程及上述长测。正式发布另外要求 Windows checks、真实冻结 EXE、安装/卸载，以及从 **v0.11.0 和 v0.12.0** 便携版/安装版升级、重启自检和用户数据哈希保护验证全部通过。发行验证不操作个人安装或语音服务。性能报告见仓库 docs/performance-stability.md 与 docs/performance-report.md。

Source validation includes 177 unit tests, 30 native UI workflows and the long-running measurements above. Publication additionally requires Windows checks, actual frozen executable and installation/uninstallation tests, and upgrades from both **v0.11.0 and v0.12.0** portable/installed packages with restart self-tests and personal-data hash checks. Validation does not operate personal installations or speech services.
